# ctx_index

Claude Code의 **auto compact** 환경에서 **맥락(context) 손실을 최소화**하기 위한 hook 프로젝트입니다.

> 현재 초기 단계(WIP)이며, 아래 내용은 방향성을 정리한 초안입니다.

## 배경

긴 세션에서 컨텍스트 윈도우가 가득 차면 auto compact가 대화를 요약해 컨텍스트를 줄입니다.
이 요약 과정에서 아래와 같은 맥락이 누락되거나 흐려질 수 있습니다.

- 작업 목표와 현재 진행 상황
- 이미 내린 결정과 그 이유
- 작업 중인 파일, 지켜야 할 규칙·제약 사항

## 목표

- compact **전**에 꼭 필요한 맥락을 보존한다.
- compact **후**에 보존한 맥락을 세션에 다시 주입한다.
- 사용자 개입 없이 자동으로 동작하고, 설정은 최소화한다.

## 동작 방식 (초안)

| 시점 | Hook | 역할 |
| --- | --- | --- |
| compact 직전 | `PreCompact` | 보존할 핵심 맥락을 추출해 저장 |
| compact 직후 | `SessionStart` (`compact`) | 저장해 둔 맥락을 세션에 재주입 |
